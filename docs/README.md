# Jesus-Centric KJV Viewer

Simple searchable reader for the processed Jesus-centric KJV text.

## Enable GitHub Pages
1. Go to repo Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / folder: `/docs`
4. Save

The viewer expects `jesus_centric_kjv_all66.txt` to be in the same folder as `index.html` (or update the `TXT_URL` constant in the script).

## Suggest a change
The “Suggest a change” button opens a pre-filled GitHub Issue.
